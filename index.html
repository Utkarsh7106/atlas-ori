Atlas — a study in visual language

The same page, twenty-nine times.

Every page below carries identical content — the same navigation, the same headline, the same three cards, the same call to action. Only the visual language changes. Each one ends with a Design Points section documenting its palette, typography, layout logic, signature techniques, motion and five rules for rebuilding the style somewhere else.
