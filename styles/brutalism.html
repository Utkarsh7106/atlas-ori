Component reference

A modal built on the native dialog element. The browser traps focus inside it, closes it on Escape, and makes everything behind it inert. Clicking the backdrop closes it, and focus returns to the button that opened it.

Design Points

Download skill ← All styles
Style Name
Brutalism
Era / Origin
Web brutalism, roughly 2014–2018 (brutalistwebsites.com, Bloomberg, Balenciaga) — named after 1950s béton brut architecture, which exposed raw material rather than cladding it.
Color Palette
  • #ffffff — page background, never tinted
  • #000000 — text and every 1px border
  • #0000ee — the browser's default unvisited link blue, deliberately untouched
  • #551a8b — the browser's default visited purple
  • #ff0000 — pure red for hover inversion
  • #e60000 — the blinking cursor
  • #c0c0c0 — system grey for table headers and the nav band
Typography
Times New Roman for everything structural, paired with Courier New for machine annotations — both browser defaults, no webfont is loaded at all. Weights are only 400 and 700 because that is all the default stack guarantees. Sizes come straight off a document scale: 48px h1, 36px h2, 22px h3, 16px body, 11–13px mono. Line-height sits at a cramped 1.35 and no tracking is applied anywhere.
Layout Logic
There is no grid and no max-width: every block is a full-bleed <section> with an 8px pad and a 1px black border, stacked in source order with zero margin so borders collide into shared 2px seams. The feature row is a real <table> with border-collapse, because a table is the honest element for tabular content.
Signature Techniques
  • Default browser link styling preserved intact — blue, purple when visited, always underlined.
  • Visible structural annotations (<nav>, <section id="cta">) printed in mono above each block, so the page documents its own markup.
  • Buttons rendered as bracketed text links — [ Explore ] via ::before/::after — rather than as styled objects.
  • Uniform 1px black borders with no radius, no shadow, and no margin collapse control.
  • A live mono status line and a blinking READY_ cursor driven by setInterval, in the register of a terminal rather than a product.
Motion/Interaction
Deliberately unrefined: there is not a single transition on the page, including on everything added since. Hover states snap instantly to a red background with the page's darkest neutral as text. JS blinks the READY_ cursor by toggling visibility every 600ms — because that is a script-driven interval rather than CSS, it is guarded by a matchMedia check and the cursor is left solid when prefers-reduced-motion is set — and writes the document's real viewport width and load timestamp into the mono status line, updating on resize; information, not decoration. Two bracketed controls sit in the nav, written in the same [ ] form as every other action: one moves the nav between a stacked box and a fixed left rail by changing a single --rail token, the other flips data-theme. Dark mode is not an inversion — it swaps in the browser's own dark defaults, including the dark-mode UA link colours — and both controls persist to localStorage. The component reference opens a native <dialog> with showModal(), which supplies the focus trap, Escape and an inert background, and returns focus to its trigger on close.
Common Mistake
Restyling links or adding a webfont "for polish." The entire point is unmodified browser defaults — #0000ee links, Times New Roman; the moment either is touched, this stops being brutalism and becomes a plain page with a brutalist theme layered on top.
Production Caveat
There is not a single CSS transition on the page by design. Any future interactive state added without matching that constraint — a smooth hover fade, an eased reveal — will visually contradict the rest of the page immediately.
Accessibility Risk
One of the safer styles here by construction: default link colours and states are exactly what a screen reader or user stylesheet already expects. The 1.35 body line-height is tighter than WCAG's 1.5 recommendation, though, and is inherited unchanged from the document default this page deliberately never overrides.
When Not To Use
Consumer e-commerce or any context where trust signals matter. Deliberately raw, undesigned pages can read as broken or unfinished to a non-technical audience rather than as an intentional statement.
Replication Rules
  1. Load no webfonts. Use Times New Roman for content and Courier New for machine text, at browser-default sizes.
  2. Leave links at #0000ee, underlined, with visited purple intact — never restyle an anchor into a button.
  3. Give every block a 1px solid black border, 8px padding, no radius, no shadow, no margin, and let borders touch.
  4. Ban all transitions and animations except utilitarian ones (a blinking cursor, a live counter); hover states must snap.
  5. Expose structure instead of hiding it — print tag names, use real tables for tabular data, and let the page read as a document rather than a product.
