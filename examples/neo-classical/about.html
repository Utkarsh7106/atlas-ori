The Practice

About

Providence, Rhode Island. Practicing since 2009.

I trained as a classicist before I trained as an architect — which mostly means I still start a building with a module and a column count before I start with a floor plan.

The practice takes on civic and institutional work almost exclusively: courthouses, libraries, small chapels, the kind of building a town expects to still be using in a hundred years.

Approach

One module, no exceptions

Every dimension in a building — bay width, ceiling height, window spacing — derives from a single fixed module set at the start of the project.

Materials

Built to weather, not to launch

Stone, brick, and cast concrete are chosen for how they age over decades, not for how they photograph on the day of handover.
