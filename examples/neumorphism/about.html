About

Freelance, Portland OR, since 2020.

I spent four years designing for a meditation app before going independent, which is where I learned that a wellness product's interface is part of the product — a UI that demands effort works against the thing it's supposed to help with.

Now I take on product design work for apps built around a daily habit: meditation, sleep, breathing, journaling. The work is usually about removing screens, not adding them.

Process

Every project starts with the single action a user repeats daily, and works outward from there.

Availability

One engagement at a time, typically 6–10 weeks, currently booking for next quarter.
